learning and memory

behavioral, cognitive, and neural mechanisms of learning and memory

Learning and Memory is an in-depth exploration of the principles, applications, and issues related to how organisms acquire, store, and retrieve information. The course approaches learning and memory from both basic and applied perspectives: students examine highly controlled laboratory studies while also considering real-world applications in education, clinical psychology, legal contexts, and everyday life.

Learning and memory sit at the intersection of biology, cognition, and experience. In this course, students explore how changes at the cellular and neural level translate into lasting behavioral change, how memory can be both remarkably accurate and surprisingly malleable, and how evidence-based learning strategies can improve studying, retention, and transfer beyond the classroom.

Learning Objectives

By the end of the course, students will be able to:

  • Analyze the behavioral, cognitive, and neural mechanisms underlying learning and memory processes in both human and non-human research contexts.
  • Evaluate experimental methods and empirical findings from learning and memory research, assessing their strengths, limitations, and validity.
  • Compare major theoretical frameworks in learning and memory science, including associative models, information processing approaches, and multiple memory systems.
  • Apply evidence-based principles from learning and memory research to optimize performance in educational, clinical, legal, and everyday contexts.
  • Design personalized, evidence-based strategies to improve learning, memory retention, and knowledge transfer.

Course Structure

The course follows a recurring weekly rhythm designed to connect behavior, brain, and application:

  • Behavioral Processes: Students begin by examining what learning and memory look like in action and how psychologists study them through carefully designed experiments.
  • Brain Substrates: Midweek work connects behavior to the neural structures and biological processes that make learning and memory possible.
  • Clinical and Applied Perspectives: Students end the week by applying course concepts to real-world challenges, including how learning and memory function, and sometimes malfunction, in educational, clinical, legal, and everyday contexts.

Teaching Approach

This course uses the science of learning to teach the science of learning. Students regularly practice the same evidence-based strategies they study, including preparation, active participation, retrieval practice, spacing, application, and reflection.

  • Retrieval Practice: Students complete regular low-stakes retrieval practice activities aligned with course readings and concepts. These activities support exam preparation while modeling the memory principles discussed in class.

  • Active Application: Class sessions include worksheets, demonstrations, discussion, and group problem-solving tasks that ask students to diagnose mechanisms, interpret examples, and apply theory to real situations.

  • Module Projects: Students complete two major projects, one focused on learning processes and one focused on memory processes. These projects emphasize depth, application, empirical research, and scientific reasoning.

  • Coded Demonstrations: I use interactive demonstrations to help students experience key phenomena in learning and memory research.
